Full syllabus

Module 1 — Start Right

  • What a spreadsheet really is
  • Enter data the right way
  • Move, select, and fill without fear

Module 2 — Clean the Data

  • The safe cleaning pattern
  • Find and remove duplicates
  • Fix text — spaces, case, and split values
  • Fix dates and missing values

Module 3 — Core Formulas That Must Be Right

  • Your first calculated column — net revenue
  • SUM, AVERAGE, COUNT, COUNTA, MIN, MAX

Module 6 — Honest Charts

  • Pick the right chart
  • Build a clean column chart
  • The honesty rules — axes, scales, and labels
  • Line charts and trend claims

Module 7 — The Dashboard and the Decision

  • Plan the dashboard before you build it
  • Build the dashboard sheet
  • Check the work — the audit pass
  • Present the decision
  • Capstone — the full Northlight analysis
