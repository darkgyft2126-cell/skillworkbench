Full syllabus

Module 1 — Plan the Research

  • Turn a topic into questions
  • Decide what proof you need
  • Set the source standard first
  • Outline before you search
  • Name the reader and the decision

Module 2 — Gather with Sources

  • Ask for sources you can open
  • Open every source yourself
  • Notes that keep the link attached
  • Spot summaries that drift from the source
  • Search in rounds: broad, then narrow

Module 3 — Judge What You Found

  • Who published this, and why
  • Old facts in new clothes
  • Two sources or it is a rumor
  • Conflicting numbers: what to do
  • Check the date and the method

Module 4 — Draft the Report

  • Structure: answer first, evidence after
  • Draft section by section
  • Tables that carry the comparison
  • Write the limits into the report

Module 5 — Check Before It Ships

  • The claim-by-claim audit
  • Numbers rechecked against sources
  • Names, dates, and titles exact
  • The read-aloud test
  • The second reader pass

Module 6 — Deliver and File

  • One-page summary for busy readers
  • File sources with the report
  • Update the report when facts change
  • Capstone: a complete short research report
