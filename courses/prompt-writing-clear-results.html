Full syllabus

Module 1 — Start with the Job, Not the Tool

  • Say what done looks like
  • Give the material the tool needs
  • Set length, tone, and format
  • Ask for a draft, then direct the edit
  • Pick one tool and learn its shape

Module 2 — The Four-Part Request

  • Part one: the job
  • Part two: the material
  • Part three: the limits
  • Part four: the return format
  • The full request, start to finish

Module 3 — Fix Weak Answers

  • Name what is wrong in one sentence
  • The repair loop: keep, cut, add
  • Ask for two versions and choose
  • When to stop and write it yourself

Module 4 — Everyday Writing Tasks

  • Emails from bullet points
  • Summaries that keep the point
  • Turn notes into clean lists
  • Rewrite for a different reader
  • Plans, steps, and checklists from a goal

Module 5 — Numbers and Tables

  • Ask questions about a table
  • Turn text into a table
  • Check every number the tool gives you
  • Formulas explained in plain words
  • Explain a chart or result in plain words

Module 6 — Build Your Prompt Library

  • Save the prompts that work
  • Name and file your library
  • Share prompts with your team
  • Capstone: your ten-prompt starter library

The SkillWorkbench course format

Every course on SkillWorkbench follows one format, built to be easy to follow:

  • Full written lessons in plain language — no filler, no jargon left unexplained.
  • A narrated video for each module that walks through the module's core ideas.
  • An infographic for each module — the whole module on one page, to keep and pin up.
  • Tables inside lessons wherever a comparison, a schedule, or a checklist reads better as a table.
  • An exercise in every lesson, with the answer — you practice, then check yourself.
  • Downloadable tools — templates, worksheets, and checklists you keep and use in real work.
  • A capstone that ends in a finished piece of work, not just a quiz.
  • A completion certificate when you finish. It records completion; it is not a professional certification.

Self-paced throughout: no schedule, no live sessions, nothing expires while your membership is active.
